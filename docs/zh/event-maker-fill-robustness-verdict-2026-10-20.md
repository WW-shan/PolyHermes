# Event Maker 成交假设稳健性与最终可行性判断（2026-10-20）

> 问题：在正确的活动门槛、Guard、最大挂单年龄和 8h 结算前尾部规则下，是否存在跨入场窗口稳健的配置？
> 结论：**没有。唯一能跨 1d–7d 全部通过的配置全部使用 q1（最乐观成交假设）；生产 Shadow 使用的 q20 最好只能通过 3/7 个窗口。**

## 1. 协议

- 数据：event-maker-full-v2-7d-20261019-dataset.json.gz，4,189 个市场。
- 活动门槛与 Shadow/Live 一致：30m >=3 笔 / >=50 USDC / 买卖各 >=1；2h >=20 笔 / >=500 USDC / 买卖各 >=3。
- Guard 3,600s / -0.4 / 0.5c；最大挂单年龄 1,800s；requote 300s。
- 结算前尾部规则：minRemainingSeconds=28,800（8h）。
- 价格带 0.95–0.97 / 0.97–0.99 / 0.985–0.995；退出价差 2/3/5/8/10c；offset 0/0.25/0.5/1.0c；队列因子 1/2/5/10/20/50；周期 1/3。
- 每个窗口按“0 结算亏损 + 总/训练/测试 ROI > 0 + 训练成交 >=20”筛选；训练期选参不查看测试期。

- q1 的 10 个配置全部是 p0.97-0.99_off0.25_*_q1.0_*，1d 训练 ROI +1.76%..+2.09%，测试 +1.71%..+1.92%。
- q2 在 1d–6d 有 10 个配置全通过，但 7d 失败。
- q5/q10 最好 5/6（1d–6d）。
- q20 最好只通过 3/7 个窗口；q50 一个都没有。

## 4. 为什么这是决定性的

q1 与 q20 的差别是成交假设，不是策略逻辑：

- q1：累计反向成交达到 1 倍订单股数就认为成交；
- q20：需要 20 倍（约 500 股）反向成交。

生产 Shadow 使用 q20，因为它是保守基线。实验结果说明：

> 策略的正收益完全依赖“很容易成交”的假设；一旦按保守成交模型，跨窗口的零亏损/正收益就不存在了。

这与基础失败率分析一致：

- 0.97–0.99 价格带的 favorite 基础失败率是 1.60%–2.85%；
- 每回合 1c 收益约 1.0%，覆盖不了 1.6% 的失败率；
- 只有把每回合收益提高到约 2.9%（3c 宽退出）才有 margin，但宽退出会把更多仓位拖到结算，增加暴露；
- q1 的高成交数把大数定律用起来，但 q20 下成交太少，尾部事件的主导作用无法被平均掉。

## 5. 结论

1. **当前 Event Maker 策略族不能实盘。** 不是因为参数没调好，而是在保守成交模型下没有跨窗口稳健的配置。
2. **不应把 q1/q2 的结果当作生产证据。** 那等于放宽成交假设，正是之前明确禁止的做法。
3. **不应跟单目标地址。** 公开成交数据无法复现他的队列位置、撤单节奏和实时风险控制。
4. 8h 尾部规则是有价值的部分缓解（12h/1d/2d 亏损配置显著减少），但它不能把 q20 的策略变成正期望。
5. 继续这个方向需要满足以下之一：
   - 用真实 Shadow 成交校准出可信的 fill factor（不是假设）；当前 v6 是 0 fill，无法校准；
   - 找到一个事前可识别的筛选，把成交池失败率压到 1% 以下；
   - 换收益结构（对冲、分批、非二元尾部），而不是继续在 0.97–0.99 里调参。
