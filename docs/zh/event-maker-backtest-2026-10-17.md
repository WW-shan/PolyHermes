# adonpoli 式事件做市策略：历史回测与可复刻性评估

> 研究日期：2026-10-17
> 研究对象：`0x0260366a9add43c25d4f4d35d2210526c6750d88`（adonpoli / Noted-Shop）
> 数据源：Polymarket Gamma API、Data API
> 结论性质：研究回测，不构成投资建议，也不代表可以实盘上线。

## 一句话结论

**他的钱主要不是靠“猜对结果”，而是靠被动挂单、买卖价差、库存周转和流动性奖励赚的。这个方向可以学，但用公开成交数据无法证明我们已经复刻出他的 edge。**

全量 maker 回测里，唯一在训练和测试两端都为正的，是 0.95～0.97 价格带里的一个很小子集，只有 23 个成交市场；而样本更充分、训练/测试都覆盖的配置全部为负。因此当前最优决策仍然是：

> **不跟单，不上线，只把“事件做市执行框架”作为下一步纸交易研究对象。**

---

## 一、他真正赚钱的方法

### 1. 不是主动追单，而是被动成交

链上抽样解析 `OrderFilled` 后，adonpoli 的成交结构是：

| 样本 | 纯 maker | maker + taker | 纯 taker |
|---|---:|---:|---:|
| 最近 99 笔 | 89 | 10 | 0 |
| 更早 30 笔 | 29 | 1 | 0 |

这意味着公开 activity 里看到的成交价，主要是他**已经挂在订单簿上的价格**。跟单系统看到信号后再市价追，拿到的是另一条成交路径，通常更差。

### 2. 利润主要来自卖出库存，而不是持有到期

按 FIFO 近似归因：

| 平仓方式 | 已实现 PnL | 占比 | 近似 ROI |
|---|---:|---:|---:|
| SELL | +21,426 | 75.8% | 0.53% |
| REDEEM | +6,843 | 24.2% | 0.82% |

约 48% 的平仓数量在 1 天内完成，约 43% 在 1～7 天内完成。超过 30 天的仓位几乎可以忽略。

这说明他的核心循环是：

> 在高概率事件市场被动买入 → 等价格回升或买卖盘继续流动 → 用 maker 卖单把库存卖回去 → 只把剩余仓位留到结算。

### 3. 奖励是补充，不是主引擎

流动性奖励约 4,195 USDC、maker rebate 约 537 USDC、yield 约 31 USDC，合计约 4,763 USDC，约占总收益 15%。奖励证明他长期提供流动性，但主要利润仍来自价差和库存周转。

### 4. 为什么很难直接复制

- 他的成交中位数只有约 58 USDC，说明优势建立在大量小 fill 和队列位置上；
- 同一市场同一 outcome 经常同时出现买入和卖出，说明他在管理库存，不是单向押注；
- 他看到的是实时订单簿和队列，而公开历史数据只留下成交，不留下当时盘口；
- 0.1%～1% 级别的薄 edge 很容易被延迟、滑点、逆向选择和手续费吃掉。

## 二、我们复刻的回测方法

代码位置：

`backend/src/main/kotlin/com/wrbug/polymarketbot/research/eventmaker/`

入口：

`backend/build.gradle.kts` 中的 `eventMakerBacktest` Gradle task。

### 样本

- Polymarket Politics tag `2` 与 Geopolitics tag `100265`；
- 二元、非 negRisk、已结算市场；
- 结算结束日期：2024-01-01 至 2026-10-01；
- 市场成交额 ≥ 250,000 USDC；
- 全市场池 2,419 个，按结算时间均匀抽样 1,000 个；
- 最终抓取 1,000/1,000 个市场的成交历史，**失败请求 0 个**。

### 交易假设

- 只交易结算前 24 小时窗口；
- 用窗口起点前最后一笔公开成交估计 favorite 参考价；
- 只做 favorite outcome；
- 入场限价 = 参考价 − offset；
- 出场限价 = 入场价 + spread；
- 所有订单均为 maker，不主动跨价；
- 每轮订单金额 100 USDC；
- 每 300 秒允许按最新成交价重新挂单；
- 队列模型：只有累计成交量达到 `queueFactor × 下单股数` 才认为成交；
- 未卖出的库存按 0 或 1 结算；
- 不考虑 taker fee、流动性奖励和 maker rebate。

### 参数网格

- 价格区间：0.95～0.97、0.97～0.99、0.985～0.995；
- 入场 offset：0.25 / 0.5 / 1.0 美分；
- 出场 spread：0.5 / 1.0 / 2.0 美分；
- queue factor：1 / 2 / 5；
- 最大周转次数：1 / 3。

合计 **162 组配置**。

### 训练/测试切分

- 训练：结算时间早于 2026-01-01；
- 测试：结算时间晚于或等于 2026-01-01。

注意：参数网格结果是在全样本上观察的，因此时间切分只能检验“同参数在后期是否继续有效”，**不能消除参数搜索偏差**。

## 三、全量结果

### 1. 总体很差

| 指标 | 结果 |
|---|---:|
| 配置数 | 162 |
| 总收益为正的配置 | 33 |
| 平均 ROI | **-1.86%** |
| ROI 中位数 | **-1.37%** |
| 最好配置 ROI | +2.19% |
| 最差配置 ROI | -8.63% |
| 训练/测试各有 ≥20 个成交市场的配置 | 18 |
| 其中训练和测试都为正的配置 | **0** |

### 2. 唯一正收益区间集中在 0.95～0.97

表现最好的配置：

`p0.95-0.97_off1.0_spread2.0_q1.0_c1`

| 指标 | 结果 |
|---|---:|
| 可交易市场 | 43 / 1,000（4.3%） |
| 成交市场 | 23 / 43（53.5%） |
| 总投入名义本金 | 2,300 USDC |
| 总 PnL | +50.39 USDC |
| 总 ROI | **+2.19%** |
| 成交轮次 | 23 |
| SELL 平仓 | 23 |
| 结算平仓 | 0 |
| 胜率 | 100% |
| 训练段 | 14 个市场，+2.18% |
| 测试段 | 9 个市场，+2.20% |
| 平均持仓时间 | 6.52 小时 |
| 持仓时间中位数 | 5.70 小时 |

按标签和年份拆分，收益几乎完全一样：

| 分组 | 成交市场 | ROI |
|---|---:|---:|
| Politics | 10 | +2.19% |
| Geopolitics | 13 | +2.19% |
| 2024 | 6 | +2.18% |
| 2025 | 8 | +2.18% |
| 2026 | 9 | +2.20% |

这不是因为他选对了方向，而是因为：

- 23 个市场全部成功卖出；
- 平均入场价约 0.9486，平均出场价约 0.9694；
- 每轮利润基本等于约 2 美分价差；
- 没有任何一轮持有到结算。

### 3. 这个 +2.19% 不能当作可实盘证据

原因不是简单的“样本少”，而是样本少加模型假设共同造成的：

1. **只有 43/1,000 个市场进入区间。**
   正收益配置的可用市场覆盖率只有 4.3%。

2. **只有 23 个成交市场。**
   每个市场只有一轮，总名义本金只有 2,300 USDC，离真实资金规模很远。

3. **所有轮次都成功卖出。**
   回测没有捕捉到“挂出去但没人接”的情况。

4. **公开成交不等于我们的订单一定成交。**
   真实成交还取决于盘口队列、订单优先级、撤单速度和竞争者的报价。

5. **2 美分价差本身就会机械放大收益率。**
   queue factor 从 1 提高到 5 后仍有约 +2.19%，说明这套正收益对队列不敏感，主要因为 100 USDC 订单相对于市场成交量太小。

6. **参数是在 162 组里挑出来的。**
   时间切分是正向的，但不能代替独立样本验证。

7. **与 adonpoli 的真实 ROI 不一致。**
   他的 SELL ROI 约 0.53%，REDEEM ROI 约 0.82%，整体约 0.33%；我们的最好配置是 2.19%。差距太大，更像是回测选择了一个特殊尾部区间，而不是复刻了他的实际经济结构。

### 4. 0.97～0.99：训练赚钱，测试转负

基准配置：

`p0.97-0.99_off0.5_spread1.0_q2.0_c3`

| 指标 | 结果 |
|---|---:|
| 可交易市场 | 112 |
| 成交市场 | 50 |
| 总轮次 | 74 |
| SELL / SETTLE | 73 / 1 |
| 总 PnL | -25.12 USDC |
| 总 ROI | **-0.34%** |
| 训练 ROI | +1.02% |
| 测试 ROI | **-0.81%** |
| 最大回撤 | 100 USDC |

73 次小价差盈利被 1 次 -100 USDC 的结算亏损完全吃掉并转负。这是典型的高胜率、负偏态收益结构。

该区间最好的配置也只有约 +0.26%，且测试段为 **-0.37%**。

### 5. 0.985～0.995：全区间亏钱

该价格带 54 组配置全部为负：

- 平均 ROI：**-4.62%**；
- 最差 ROI：**-8.63%**；
- 最好配置：-2.49%，训练 -2.29%，测试 -2.74%。

以该价格带的“稳健”配置为例：

| 指标 | 结果 |
|---|---:|
| 成交市场 | 48 |
| 总轮次 | 67 |
| SELL / SETTLE | 65 / 2 |
| 胜率 | 97.0% |
| 总 PnL | -167.08 USDC |
| 总 ROI | **-2.49%** |

65 次 SELL 合计约 +32.92 USDC，2 次结算亏损合计 -200 USDC。胜率 97% 仍然大亏，原因就是尾部风险。

## 四、最终判断

### 能学到的

- 做市盈利的核心是价差、库存周转和成交质量，不是“看到大 V 买入就追”；
- 用 maker 单而不是 taker 单；
- 选择高成交额、规则清晰、临近结算的政治/地缘事件；
- 小单、多市场、分散事件；
- 目标持有数小时到数天，不做长期债券持有；
- 高胜率不等于安全，必须盯着一次结算亏损能否吃掉几十/几百次盈利；
- 0.99 以上和 0.985～0.995 不能重仓。

### 学不到的

- adonpoli 的实时订单簿和队列位置；
- 他的撤单、改单、报价更新和库存上限；
- 他看到的新闻/事件流和反应速度；
- 他在真实竞争中的 fill rate 和 adverse selection；
- 他控制尾部风险的具体仓位规则。

### 当前不能做什么

1. **不要逐笔跟单 adonpoli。**
   他的公开成交是 maker 成交，跟单只能 taker 追价，结构上已经输了。

2. **不要实盘上线这个 +2.19% 配置。**
   它只有 23 个成交市场、全部 sold、订单规模 100 USDC，且没有真实盘口验证。

3. **不要把 97%～100% 胜率当成安全。**
   0.985～0.995 的回测已经展示了 2 次结算亏损如何抹掉 65 次盈利。

### 下一步若要继续

先做 **maker 纸交易模拟器**，而不是直接下单：

- 采集真实 L2 订单簿与逐笔成交；
- post-only 挂单，记录排队位置、撤单、重挂；
- 记录每个 fill 的 markout（1 分钟 / 5 分钟 / 30 分钟）；
- 按真实 maker fee、reward、rebate 计算净收益；
- 加入资金并发约束，而不是每个市场都假设有独立 100 USDC；
- 测试订单规模 100 / 1,000 / 10,000 USDC 的容量衰减；
- 至少覆盖 100 个结算事件、4～8 周纸交易；
- 只有在纸交易中同时看到正期望、可控回撤和稳定 fill rate，才考虑极小资金实盘。

## 六、最终结论

> **他的方法可以学习，但不能被这份历史成交回测证明为可复刻。**
> **真正值得复刻的是 maker 执行和库存管理框架；真正需要补的是实时订单簿、真实 fill 和 adverse selection 数据。**
> **在这些数据齐备之前，不跟单、不实盘。**
